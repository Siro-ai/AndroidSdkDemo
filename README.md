There are two important modules in this repository:

1. [`/recorder`](/recorder/src/main/java/com/siro/recorder)
   - contains the SIRO SDK that can be imported into any app to launch a voice recorder and upload manager service.

2. [`/sdk-demo`](/sdk-demo/src/main/java/com/siro/demo)
   - contains a demo app that shows how to launch the Siro SDK and how to receive and present the recorder and upload states.
